LES CARNETS NOMADES — VERSION RESPONSIVE

1. Extraire ce ZIP dans un nouveau dossier.
2. Ouvrir index.html avec Google Chrome ou Microsoft Edge.
3. Agrandir / réduire la fenêtre pour voir les versions ordinateur et mobile.
4. Cliquer sur les liens du menu pour parcourir les pages.

Le site utilise les polices Google et Tailwind CDN sur 7 pages : une connexion internet est nécessaire pour le rendu complet.
Les photos restent à ajouter. La page La Team est provisoire, le code Stitch original étant absent.
Ce dossier est un site HTML statique, sans administration de blog ni publication en ligne.
